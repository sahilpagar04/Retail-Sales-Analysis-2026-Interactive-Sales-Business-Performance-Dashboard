# Retail-Sales-Analysis-2026-Interactive-Sales-Business-Performance-Dashboard

1. Poject Overview
The Sales Analytics Dashboard is an interactive Microsoft Excel project developed to analyze and visualize retail sales data.

The objective of this project is to transform raw sales transaction data into meaningful business insights that help organizations understand sales performance, product and category contribution, customer behavior, regional performance, order channels, payment methods, delivery efficiency, customer ratings, returns, and order trends.

The dashboard uses Data Cleaning, Pivot Tables, KPIs, Charts, Slicers, and interactive visualizations to provide a comprehensive view of overall sales performance and support data-driven business decisions.

2. Project Objectives
- Clean and prepare raw transactional data. 
-  Perform exploratory data analysis using Excel. 
-  Build calculated fields and business metrics. 
-  Create Pivot Tables for multidimensional analysis. 
-  Develop interactive KPIs. 
-  Analyze monthly sales performance. 
-  Identify top-performing products and categories. 
-  Analyze sales across regions and cities. 
-  Compare order channels. 
-  Understand customer payment preferences. 
-  Analyze delivery performance. 
-  Monitor customer ratings. 
-  Analyze return and order status patterns. 
-  Build an interactive dashboard using Excel slicers and filters. 
-  Convert data into business-oriented insights for decision-making.  with bullet points
